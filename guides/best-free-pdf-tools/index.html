What makes a free PDF tool worth using?

Most PDF jobs are small, so the tool shouldn't cost more than the job is worth, in money or privacy. We judge a free PDF tool on four things:

  • It runs locally. The file is read and processed by JavaScript in your browser tab. Nothing is uploaded, so there's no server copy to worry about.
  • No watermark. The output should look like your document, not an ad for the site that made it.
  • No sign-up. An email wall for a one-minute task isn't free, it's a trade.
  • It keeps quality. Merging or splitting shouldn't re-render your pages. Text should stay selectable and images shouldn't get recompressed unless you asked for that.

Many popular PDF sites process files on their own servers. Some cap free use, add watermarks or ask you to sign up after a few files. Terms change often, so check any site's current limits before you rely on it. We compare the big names in Smallpdf alternatives and free Adobe Acrobat alternatives. Which tools handle pages?

Merge PDF takes a stack of files, lets you drag them into order, and copies every page into one document. Text stays selectable and images keep their resolution because nothing is re-rendered. Our guide on how to merge PDFs covers the edge cases, like signed files.

Going the other way, Split PDF cuts one file into many, while Extract PDF Pages keeps one subset as a single new file. If you'd rather point and click, Delete Pages, Rearrange PDF Pages and Organize PDF all show thumbnails.

One honest catch: the delete and rearrange tools build a brand-new PDF from copies of your pages. Page content comes through intact, but document-level bookmarks don't. Rebuild any clickable outline afterward. Rotate PDF doesn't have that problem, since it only changes each page's stored rotation. Crop PDF sets a visible area, so it's reversible, and that's also why it's no good for hiding anything.

Which tools convert to and from PDF?

For images, JPG to PDF embeds your JPEGs as they are, so a batch of photos becomes a PDF of about the same size. PDF to JPG goes the other way and zips multi-page exports.

For documents, Word to PDF handles .docx files. Headings, lists, tables and links carry over, but the layout won't match Word exactly. Excel to PDF prints the values in each cell, including the last calculated result of any formula. HTML to PDF and Markdown to PDF suit invoices, notes and READMEs. If you only need to read a Word file, the DOCX Viewer opens it without converting anything.

To get text out, PDF to Text reads the text layer. Scans don't have one, so use OCR PDF for those. See how to OCR a PDF for DPI and accuracy tips.

Which tools edit, sign and mark up a PDF?

PDF Add Text stamps new text wherever you click, which covers dates, initials and filling in forms that have no fields. PDF Annotate writes proper highlight, ink and note annotations, so a colleague can still move or delete them later.

Sign PDF lets you draw or type a signature and place it on the page. That's fine for everyday forms. For contracts that need proof of who signed and when, a signing platform's audit trail is the better fit. Our guide to signing a PDF online explains the difference.

The rest are finishing touches: Watermark PDF for DRAFT or CONFIDENTIAL stamps, PDF Page Numbers for reports, and the PDF Certificate Maker for course or award certificates.

Which tools protect privacy and security?

This is where the details matter most. A black rectangle drawn over text isn't redaction, because the words are still in the file. Redact PDF rebuilds each page as an image with your boxes burned in, so the covered text is gone for good. The trade-off is that the whole document loses its text layer. Read how to redact a PDF before you send anything sensitive.

Password Protect PDF applies AES-256 encryption. The open password is the strong part. Print and copy restrictions depend on the reader software playing along. If you need to take a password off a file you own, there's a separate remove PDF password page.

For metadata, the PDF Metadata Editor is good for fixing a title or author. To scrub a file before sharing, use the Document Metadata Remover, which clears the XMP block too. Flatten PDF turns filled form fields into ordinary page content so nobody can quietly change them.

Which tools fix and compare PDFs?

When a PDF won't open, Repair Corrupt PDF rebuilds the file's internal index and salvages the complete pages it can find. It fixes structure, not rendering, so a file that opens with blank pages usually needs something else. Compare PDFs shows word-level changes between two versions, which beats reading both side by side. It won't catch font or image changes.

The offline test is the simplest. Some tools load their processing code only when you first use them, so run the task once while online, then go offline and run it again. If it fails with no connection, the file is probably going to a server.

When should you use desktop software instead?

Browser tools are limited by your device's memory. Everyday documents are fine, but a scan of several hundred pages at high resolution can slow a tab down or crash it. OCR is the biggest example. It runs on your processor, page by page, and a long file takes a while. Desktop OCR software is usually faster on big batches.

Desktop apps also make sense if you edit PDFs daily, need to change existing text in place, or work with accessibility tagging. For the occasional merge, split, sign or compress, a browser tool is quicker and keeps the file on your machine.

Frequently Asked Questions

Are free PDF tools safe to use for private documents?

They can be, if the processing happens in your browser. A tool that runs locally never sends the file anywhere, so there's nothing on a server to leak or retain. Test it: load the page, switch off Wi-Fi, and run the task. If it still works, the file stayed on your device.

Why do some free PDF sites add a watermark?

Usually because server processing costs them money, so the free tier is a trial and the watermark nudges you toward a paid plan. Tools that run in your browser don't carry that cost per file, so there's no reason to stamp the output. Check the terms of any site you use, since limits change.

Can I merge PDFs without uploading them?

Yes. The ToolAspect PDF merger reads your files into browser memory with the pdf-lib library, combines them in the order you drag them into, and hands back a download. Encrypted files need to be unlocked first. Nothing is sent to a server.

Does drawing a black box over text redact a PDF?

No. A box drawn on top leaves the text underneath in the file, where anyone can copy or extract it. Real redaction removes the content. The ToolAspect redact tool rebuilds each page as an image with your boxes burned in, so the covered text is gone. The trade-off is that the whole file loses its selectable text.

What's the largest PDF a browser tool can handle?

There's no fixed cap, but the file has to fit in your device's memory while it's being processed. A laptop copes with most everyday documents. Very large scans, hundreds of pages at high resolution, or OCR on long files can get slow or run out of memory, and that's when desktop software is the better choice.
