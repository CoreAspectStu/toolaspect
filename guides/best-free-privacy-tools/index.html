How do I remove location data from a photo before sharing it?

Open Image Metadata Remover, choose the photo and download the clean copy. The tool redraws the picture without its EXIF block, so GPS, timestamps and the phone model are gone. If you want to see what was there first, drop the original into the EXIF Viewer.

This matters more than people expect. Social networks usually strip location from what they show, but emailed photos, cloud share links and files sent through chat apps often keep it. A photo of your new sofa can carry your home's coordinates to a few meters. Our guide on removing location from photos also covers the built-in switches on iPhone and Android.

How do I clean a Word document or PDF before sending it?

Office files record who wrote them, who last saved them, the company name from the software license and how long the document was open for editing. That's awkward when a CV still says it was written by your current employer's IT department.

Document Metadata Remover clears those properties from Word, Excel, PowerPoint and PDF files and gives you a clean copy. It doesn't touch the body, so accept or reject tracked changes and delete comments in Word first. For a PDF that needs a sensible title rather than a blank one, use the PDF Metadata Editor. And if a PDF has names or numbers that shouldn't be there at all, Redact PDF is the tool. How do I check a QR code or link before opening it?

QR codes on parking meters, restaurant tables and flyers are an easy way to send someone to a fake payment page, because you can't read the link by looking at the code. Most phone cameras show a preview of the address before opening it, but it's small and easy to tap past.

Our QR Code Scanner decodes the code and shows you the full text first, with a separate button to open it. Read the domain carefully. A parking app's real address won't end in an odd country code or have extra words bolted onto a brand name. If a code is stuck on top of another one, that's a warning sign on its own.

The same habit works for login tokens and certificates if you're a developer. The JWT Decoder shows exactly what a token reveals about a user, which is often more than people assume, since a JWT's payload is only encoded, not encrypted.

Can a free tool tell if a photo is fake or AI-generated?

Partly. Our AI Image Detector reads the file's metadata for signs such as camera data, editing software tags and generator names. When those are present they're a useful clue. When they're missing, it tells you nothing, because screenshots, messaging apps and social networks strip metadata from real photos too.

For a picture of a person, a reverse search is often more revealing. Reverse Image Search checks four engines at once, so you can see whether the same image has been posted elsewhere under another name. Our TinEye alternatives guide compares what each engine is good at.

Which outside privacy tools are worth installing?

Some jobs need an app rather than a web page. These four are free, widely trusted, and cover what browser tools can't.

  • Bitwarden. An open-source password manager whose free plan stores unlimited passwords across unlimited devices. Pair it with our Password Generator or its own.
  • Have I Been Pwned. Tells you which known breaches include your email address. Its password check uses a technique called k-anonymity, so only the first five characters of your password's SHA-1 hash ever leave your device.
  • uBlock Origin. A content blocker that cuts ads and trackers. On Firefox you get the full version. Chrome now supports only the lighter uBlock Origin Lite.
  • Signal. End-to-end encrypted messages and calls, run by a nonprofit, with very little metadata kept about who talks to whom.

How strong does a password need to be?

Long and random beats clever. A 16-character random password or a passphrase of five or six random words is out of reach for offline cracking rigs. Swapping letters for symbols, like "Tr0ub4dour&3", isn't. Our Password Strength Checker rates that famous example at about 41 seconds against a fast offline attack.

The bigger risk is reuse. One leaked password tried against your other accounts does more damage than any brute-force attack. That's why a password manager tops this list. For the numbers behind crack times, see what makes a password strong.

Frequently Asked Questions

How can I tell if a privacy tool uploads my files?

Open your browser's developer tools, go to the Network tab and run the tool on a test file. If the file is processed locally, you won't see a large upload request carrying it. You can also load the page, switch off Wi-Fi and try again. A tool that still works offline isn't sending your file anywhere.

Does posting a photo on social media remove the GPS location?

The big platforms such as Facebook, Instagram and X strip location data from the copies they display. Email attachments, cloud share links, AirDrop and many messaging apps sent as files usually keep it. Stripping the metadata yourself before you share is the only way to be sure.

Is drawing a black box over text in a PDF enough to hide it?

No. A box drawn on top leaves the original text in the file, so anyone can copy it out or delete the box. Real redaction removes the content underneath. ToolAspect's Redact PDF rebuilds each page as an image with your boxes burned in, so the hidden words no longer exist in the file.

Is it safe to type my real password into a strength checker?

It's better not to, even with one that runs locally like ours. Test a password built the same way, with the same length and kind of characters, rather than the real thing. If you want to know whether a real password has leaked, Have I Been Pwned's password check is designed for that and never receives the full password.

What's the single most useful free privacy tool?

A password manager. Reused passwords cause more account takeovers than anything else on this list, and Bitwarden's free plan stores unlimited passwords on unlimited devices. After that, stripping location data from photos before you send them is the habit that catches people out most often.
