How to Delete Pages From a PDF

📄 6 min readUpdated October 15, 2026

You don't need Acrobat to delete pages from a PDF. A Mac can do it in Preview, any computer can do it with Chrome's print dialog, and a browser tool can do it without uploading the file. The method matters more than people expect, though. Some rebuild the file and quietly drop bookmarks, form fields or the title. And in one case we tested, an image from a deleted page was still sitting inside the new file. Here are the options, what each keeps, and how to check the result.

The print-to-PDF trick works anywhere, but it's a blunt instrument. Printing re-creates the document from what's drawn on screen, so anything interactive tends to disappear. That's fine for a scanned contract. It's a problem for a form someone still has to fill in.

Is a deleted page really gone from the file?

Usually, yes, but not always completely. A PDF isn't a stack of pages. It's a collection of objects (text streams, fonts, images) and a page tree that points at them. Deleting a page removes the pointer. Whether the page's content goes with it depends on how the tool rebuilds the file.

We tested the method our delete tool uses: copying the kept pages into a brand-new document with pdf-lib, the same library and version (2.5.1) the tool loads. We built a 10-page test PDF with a title and author, a bookmark, a filled form field on page 2, a web link on page 3 and an image on page 5, then deleted page 5. Here's what came out:

The shared-resource case is the one to know about. Some PDF generators, including a few scanners and reporting tools, give every page the same list of images and fonts instead of a list per page. Copying a kept page then drags the whole list along, including images that only appeared on the page you deleted. Nobody will see them by scrolling, but anyone with an extraction tool could pull them out.

So if you're deleting a page because it holds something sensitive, like a bank statement page in an application pack, don't rely on deletion alone. Either redact first, or flatten the kept pages to images, which rebuilds them from pixels and leaves nothing behind.

Why did my file barely get smaller?

Usually for the reason above: shared fonts and images stay because the kept pages still reference them. A 20-page document using one embedded font won't shed that font when you delete 15 pages. In our shared-resource test, the trimmed file was actually larger than the original (6,666 bytes vs 6,457), because the rebuilt file is written without the compact object streams the original used.

If size is the real goal, delete the pages first, then run the result through Compress PDF. Scanned documents shrink the most, since each page is a full image.

Can I delete pages from a password-protected PDF?

If it only has an open password and you know it, you can remove the password first with our PDF password tool, delete the pages, then re-protect the trimmed copy. Browser tools that rebuild the file can't read encrypted content without the password, so that order matters.

If the PDF has a permissions password that blocks editing and you don't know it, ask whoever sent it for an unlocked copy. Working around those restrictions on someone else's document is a bad idea even when it's technically possible.

How do I check the result before sending it?

  • Count the pages in the viewer's thumbnail panel. Mixed-up page numbers are the most common mistake, especially when a document has roman-numeral front matter and the viewer's page 5 isn't the printed "5".
  • Search for a word that only appeared on a deleted page. If it turns up, the page didn't go.
  • Click a link and try a form field if the recipient needs them.
  • Keep the original. Every method except Preview and the iPhone Files app writes a new file. With those two, duplicate first.

Frequently Asked Questions

How do I delete pages from a PDF for free?

Use a free browser tool such as ToolAspect's Delete Pages from PDF: open the file, click the × on each page you don't want, and download. On a Mac you can also use Preview's thumbnail sidebar, and on any computer you can print to PDF with only the pages you want to keep.

Can you delete pages in Adobe Acrobat Reader?

No. Deleting pages is part of Organize Pages, which needs a paid Acrobat Standard or Pro subscription. The free Reader can view, comment and sign, but can't remove pages.

Does deleting a page from a PDF permanently remove it?

The page and its text are removed from the new file. But if the PDF shares one list of images across all pages, an image from a deleted page can remain hidden inside the file. For sensitive pages, redact or flatten instead of relying on deletion.

Why didn&#x27;t my PDF get smaller after deleting pages?

Fonts and images shared with the pages you kept stay in the file, and a rebuilt file can be written less compactly than the original. Run it through a PDF compressor afterward if size matters.

Can I undo deleting pages from a PDF?

Only if you kept the original. Browser tools and print-to-PDF write a new file and leave the original alone. Mac Preview and the iPhone Files app edit in place, so make a copy before you start.
