Why Can't I Edit My PDF?

📄 6 min readUpdated October 17, 2026

If you can't edit a PDF, it's almost always one of a few things: the page is a scanned image, the file has a permissions password, the form fields were flattened, or the app you're using is a viewer rather than an editor. Each one has a different fix, and most don't need paid software. Find your symptom below, then pick the right tool for the edit you actually need to make.

Why is my PDF not editable?

PDF was built to look the same everywhere, not to be edited. Inside the file, a line of text is a set of instructions: draw these glyphs, in this font, at these coordinates. There are no paragraphs and no word wrap. Change a word and the editor has to guess how the rest of the line should move. That's why even paid editors struggle with more than small fixes, and why most free apps don't try.

How do I tell if my PDF is a scan?

Try to select a single word, or press Ctrl+F (Cmd+F on a Mac) and search for something you can see on the page. If nothing highlights, the page is an image. Scanners, phone scanning apps and "print to PDF" from some photo apps produce exactly this: a picture of a document wrapped in a PDF.

No editor can change words that aren't text. Run the file through OCR first. Text recognition reads the page images and adds real, searchable text. Check the result before you rely on it, since OCR often misreads small print, tables and handwriting. If you only need the words, pull them into a plain text file with PDF to text and edit them anywhere.

Why does my PDF say it's secured?

PDFs can carry two different passwords. An open password stops anyone without it from viewing the file. A permissions password lets everyone open the file but restricts editing, copying or printing. Many readers then grey out their edit tools and add "SECURED" to the title bar.

The permissions password is a request to the software, and it's honored by well-behaved apps. The polite and legal route is to ask whoever sent it for an editable copy. If it's your own file and you know the password, our PDF password tool can remove the encryption in your browser. We'd skip any site that offers to crack a password on a file that isn't yours.

Why can't I type in a PDF form?

A fillable form has interactive fields. Many forms don't: they were scanned, exported from Word without fields, or flattened, which bakes the fields into the page. You can click all you like and nothing happens.

The workaround is to type on top. An add-text tool lets you click where each answer goes and place text there. If the form does have fields but shows a "please wait" message or a blank page, it's probably an XFA form, an older Adobe format most browsers and Mac Preview can't run. Open it in Adobe Acrobat Reader, which is free. More on that in our guide to filling out PDF forms.

Can I edit a signed PDF?

You can, but you'll break the signature. A digital signature includes a fingerprint of the file at the moment it was signed. Change anything and the signature shows as invalid or modified. Certified documents go further and can lock fields after signing. For contracts that's the point: it proves nobody changed the terms. To make changes, edit the original document and get it signed again.

A drawn or typed signature image is different. It's just a picture on the page, and nothing breaks if you edit around it.

Which tool do I need for my edit?

Most of what people call "editing a PDF" isn't changing existing text. It's adding something, removing something or moving pages, and those are easy:

If you really do need to rewrite paragraphs, the best answer is almost always to edit the source file (Word, Google Docs, whatever made the PDF) and export a new PDF. When there's no source, LibreOffice Draw opens PDFs for free and lets you change text box by box, though layouts can shift. When text changes font after an edit, the PDF usually embedded only the characters it used. That's called subsetting, and if you type a letter that wasn't in the original, the editor has to swap in another font.

Frequently Asked Questions

Why can't I edit text in my PDF?

Usually because the PDF is a scanned image, is restricted by a permissions password, or is open in a viewer that can't edit text. Check whether you can select text first. If you can't, the page is an image and needs OCR.

How do I make a PDF editable for free?

For scans, run OCR to add a text layer. For other files, open the PDF in LibreOffice Draw, or add text, notes and signatures on top with a free browser tool. Rewriting whole paragraphs is easier in the document the PDF came from.

Why is my PDF form not fillable?

The form either never had interactive fields or was flattened. You can still complete it by placing text boxes on top with an add-text tool. If it shows a please-wait message, it's an XFA form that needs Adobe Acrobat Reader.

How do I remove editing restrictions from a PDF?

Ask the sender for an unrestricted copy. If it's your own file and you know the password, a PDF password tool can remove the encryption. Getting around restrictions on someone else's document may break their terms or the law.

Why does the font change when I edit a PDF?

Most PDFs embed only the characters they use, called a font subset. If you type a letter the subset doesn't include, or the font isn't installed on your computer, the editor substitutes a different font.
