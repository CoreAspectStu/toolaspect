Does GIF Keep Metadata?

📄 6 min readUpdated October 28, 2026

GIF has no EXIF block, so the camera details and GPS from a photo don't survive conversion. That isn't the whole story, though. GIFs can still carry comments, a color profile and XMP, and XMP can hold a location. We ran a GPS-tagged photo and a hand-built XMP GIF through Pillow, ImageMagick and a browser to see what each one keeps.

Do GIF files have EXIF data?

No. The GIF format has no place to store EXIF, the block where cameras and phones write the make, model, date and GPS coordinates. When you turn a photo into a GIF, the EXIF block has nowhere to go and gets dropped. We confirmed that with every converter we tried.

That doesn't mean a GIF is clean. GIF has extension blocks, and three of them can carry information about you or your software:

The XMP block is the one to watch. XMP can hold anything a JPEG's metadata can, including location, and in a GIF it's stored as plain XML.

Does converting a photo to GIF remove its location?

In our tests, yes. We made a phone-style JPEG with EXIF (camera, an author name and GPS coordinates), XMP and a color profile, then converted it to GIF several ways. We read every block of each output with a script that walks the GIF structure.

Pillow, the Python imaging library behind many web apps, wrote nothing, even when we passed the EXIF, XMP and profile in explicitly. ImageMagick kept only the color profile. Neither carried over the location or the author name. The one exception is a comment: both tools write one if you ask, and Pillow wrote ours as readable text.

Notice the sizes, too. The GIF came out two to four times bigger than the JPEG it came from, and limited to 256 colors. Converting a photo to GIF to strip its metadata is a bad trade. It's easier to remove the metadata from the JPEG and keep it a JPEG.

Can a GIF still carry GPS coordinates?

Yes, through XMP. Metadata tools like ExifTool can write an XMP block into a GIF. To see what happens to one, we built a GIF with an XMP block holding an author name and GPS coordinates, then ran it through the usual routes.

  • GIF to GIF with ImageMagick: the XMP survived, coordinates and all. ImageMagick even rewrote the block's ID in lowercase, but the data was still there as plain text.
  • GIF to JPG or PNG with ImageMagick: the XMP was dropped.
  • ImageMagick with -strip: removed.
  • Our image compressor (browser canvas): removed. The output is PNG, JPEG or WebP, since browsers can't encode GIF.

One thing to know about our own EXIF viewer: on that GIF it reported "No EXIF metadata found" and "No GPS data present." The EXIF part is accurate, since there's no EXIF, but the location was sitting in the XMP block and the viewer doesn't read XMP in GIFs. Until that's fixed, the quickest check is a text editor. Open the GIF and search for xmpmeta, GPS or your name. Because GIF's XMP and comments aren't compressed, a hit means it's there.

What about animated GIFs?

Animated GIFs carry the same extension blocks, plus the loop setting. The catch is that most simple strip tools ruin the animation. When we put a 12-frame animated GIF through our image compressor, it came out as a single still frame. That's how browser canvas works: it draws one frame at a time. The metadata was gone, and so was the animation.

To clean an animated GIF and keep it moving, use ImageMagick with -strip. On our test file it kept all 12 frames and the loop setting and removed the comment, cutting the file from 4,983 to 4,013 bytes. ExifTool can also delete the comment and XMP blocks without re-encoding anything.

How do I remove metadata from a GIF?

Pick the route that matches what you care about:

  • Still GIF, don't need GIF: convert it to PNG or WebP in the image compressor. Everything is stripped, and PNG keeps sharp edges on graphics.
  • Animated GIF: convert in.gif -strip out.gif with ImageMagick keeps the frames and drops comments, XMP and the color profile.
  • A photo you were going to turn into a GIF: don't. Strip the JPEG with our image metadata remover (it takes JPEG and PNG) and share it as a JPEG.

Afterwards, check the result the same way: open it in a text editor and search for xmpmeta, GPS and your name. For other formats, see whether PNG files have metadata and WebP keeps metadata.

Frequently Asked Questions

Do GIFs have EXIF data?

No. The GIF format has no EXIF block, so camera details and GPS from a photo are dropped when it's converted to GIF. GIFs can still carry comments, an XMP block and a color profile.

Can a GIF contain location data?

Yes, inside an XMP block, though no converter we tested added one on its own. Tools like ExifTool can write XMP with GPS coordinates into a GIF, and ImageMagick kept that XMP when converting GIF to GIF.

Does converting a JPG to GIF remove metadata?

Mostly. In our tests Pillow dropped everything, even when the metadata was passed in, and ImageMagick dropped EXIF, GPS and XMP but kept the color profile. Either tool can still add a text comment if asked.

How do I remove metadata from an animated GIF without losing the animation?

Use ImageMagick: convert in.gif -strip out.gif. On our test file it kept all 12 frames and the loop setting and removed the comment. Browser-based compressors usually output a single still frame.

How can I check a GIF for hidden metadata?

Open it in a plain text editor and search for xmpmeta, GPS or your name. GIF comments and XMP are stored uncompressed, so they show up as readable text. EXIF viewers often skip XMP in GIFs.
