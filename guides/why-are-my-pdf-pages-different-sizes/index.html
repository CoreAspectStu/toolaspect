Why Are My PDF Pages Different Sizes? (And How to Fix It)

📄 6 min readUpdated October 22, 2026

PDF pages end up different sizes because each page in a PDF stores its own dimensions, and merging, scanning or inserting a slide keeps whatever size the page started with. That's normal, and often harmless. Here's how to spot which pages are off, how much they shrink when you make them match, and the quickest way to fix it when it matters.

Why does my PDF have pages of different sizes?

Because a PDF doesn't have one page size. Every page carries its own dimensions, and nothing in the format says they have to match. Any time a document is built from more than one source, the pages keep whatever size they started with. These are the usual culprits:

CauseTypical exampleWhat you see
Merged from different sourcesAn A4 contract plus a Letter cover page plus a slideEvery page keeps its own size
Scanned or photographed pagesPages a few points off a standard size, or sized to the detected paper edgeSmall size wobble from page to page
Landscape pagesA wide table or chart page in a portrait reportOne page wider than the rest
Cropped pagesSome pages trimmed, others notPages look smaller in the viewer, but the original area is still there
Images saved as PDFEach photo becomes a page the size of the imageEvery page a different shape

Does merging PDFs change the page size?

No, and that's by design. A merge copies each page across unchanged, so nothing gets squashed or stretched. To check, we merged five one-page PDFs with pdf-lib, the same library our PDF merge tool uses, and read the result with pdfinfo:

Every page came through exactly as it went in. That's the right behaviour for a merge, but it explains the complaint: combine a US form with a European attachment and you get a file that jumps between 8.5 × 11 and 8.27 × 11.69 inches. The last row is a reminder that a size can be "almost A4." Viewers and print dialogs often label it A4 anyway, but it isn't quite.

How common is the mix? Not very within a single source. Of 39 PDFs we checked on our own machines, 16 were A4, 7 were Letter, 13 were 16:9 slide decks and 2 were other sizes, and none mixed A4 and Letter pages inside one file. Mixed sizes almost always come from assembling documents, not from the software that created them.

How do I check the size of each page?

  • Adobe Acrobat Reader: File > Properties shows the page size of the page you're on. Move to another page and open it again to compare.
  • Mac Preview: open the Inspector with Command-I, which shows a page size, and use thumbnails to spot pages that look different.
  • Command line: pdfinfo -f 1 -l 999 file.pdf prints every page's size and rotation in one list. It's part of Poppler and free on Mac, Linux and Windows.
  • Thumbnails: in any viewer, a mixed file gives itself away. Odd pages look wider, shorter or sit with bigger margins.

How do I make all pages the same size?

There are three approaches, and they solve different problems.

  • Print to PDF at one paper size. Open the file, choose Print, pick Microsoft Print to PDF or Save as PDF, set the paper size and choose Fit or Shrink oversized pages. Every page comes out the same size. The catch: a print-to-PDF copy usually loses links, bookmarks and fillable form fields, so keep the original.
  • Use a PDF editor's page-size tool. Acrobat Pro and some other editors can resize or "fit to paper" in place, which keeps more of the structure than printing does.
  • Leave the sizes and fix the printing. If the problem is only that pages print badly, a single Fit setting in the print dialog handles mixed sizes page by page. For many people that's all they actually need.

Our tools help with the pieces around it. The crop PDF tool trims margins by setting each page's crop box, which is the area viewers and printers show. That can make scans with ragged edges look uniform, but it doesn't scale anything, and the trimmed area is still in the file. If one page is simply sideways, it's a rotation problem rather than a size one, and rotate PDF fixes it permanently.

Does a different page size cause problems?

Mostly when printing. A mixed file printed at Actual size can clip the bigger pages and leave wide margins round the smaller ones. Some court e-filing portals and print shops also reject or flag documents that aren't a single standard size, so check their rules before you submit a merged bundle. On screen, a mixed file is harmless. It just looks a bit untidy when you scroll.

Frequently Asked Questions

Why are some pages in my PDF bigger than others?

Each page in a PDF stores its own size, so pages keep whatever size they had in the source they came from. Merged documents, scans, landscape pages, cropped pages and photos saved as PDF are the usual reasons.

Does merging PDFs resize the pages?

No. Merging copies each page across unchanged. In our test, Letter, A4, Legal and 16:9 slide pages all kept their exact sizes after being merged with pdf-lib, the library our merge tool uses.

How do I make all PDF pages the same size for free?

Print the PDF to a new PDF at one paper size with Fit or Shrink oversized pages turned on, using Microsoft Print to PDF on Windows or Save as PDF on a Mac. The new file usually loses links, bookmarks and form fields, so keep the original.

How much smaller does an A4 page get on Letter paper?

About 94.1% of its original size if it's scaled to fit with no margin, because A4 is 17.6 mm taller than Letter. Letter on A4 shrinks less, to about 97.3%.

How do I see the page size of a PDF?

In Adobe Acrobat Reader, File > Properties shows the size of the current page. On a Mac, Preview's Inspector shows a page size. The free pdfinfo command lists every page's size at once.
