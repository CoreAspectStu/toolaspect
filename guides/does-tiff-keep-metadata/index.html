Does TIFF Keep Metadata?

📄 6 min readUpdated October 29, 2026

TIFF is the format EXIF was built on, so it can hold more metadata than almost anything else: camera details, GPS, XMP, IPTC and a color profile. What actually survives a conversion depends on the software. We ran a GPS-tagged photo through Pillow and ImageMagick, read every tag in the results, and found they keep very different things.

Do TIFF files have metadata?

Yes, and more room for it than almost any other image format. EXIF, the metadata block cameras write into JPEGs, is itself built on TIFF's tag structure. In a TIFF file, those tags sit right in the main header. A TIFF can carry the full set: EXIF, GPS, XMP, IPTC and a color profile.

Scanners usually fill in make, model, software and resolution, and some scanning apps add an artist name from your computer's user account. Cameras that save TIFF, and raw formats built on TIFF like DNG and Nikon's NEF, carry full EXIF including GPS if location was on.

Does converting a photo to TIFF keep the GPS location?

It depends on the software, and the results are less predictable than you'd think. We took a phone-style JPEG with EXIF (camera, an author name and GPS coordinates), an XMP block and a color profile, converted it to TIFF several ways, and read every tag in each output with a script that walks the TIFF structure.

Two things stand out. Pillow, the Python library behind a lot of web converters, drops EXIF and GPS unless the code passes them in on purpose, but then it keeps them completely. ImageMagick did the reverse on our version: it dropped the EXIF and GPS but kept the XMP, so the author name was still in the file. Neither tool kept everything, and neither removed everything without being told to.

The compression type made no difference to metadata. ZIP and JPEG-compressed TIFFs kept the same tags as the uncompressed one. It just changed the size.

Does saving a TIFF again remove its metadata?

Sometimes. A TIFF with full EXIF and GPS, re-saved by ImageMagick as TIFF, came out with only its color profile. Re-saving or rotating it in Pillow did the same. Converting that TIFF to JPEG dropped the EXIF in both tools unless we told Pillow to copy it, and then the GPS came straight across.

The catch runs the other way with XMP. When we converted ImageMagick's TIFF to JPEG, the XMP and the author name went along with it. "I converted it, so it's clean" isn't safe with TIFF. What survives depends on which block the data is in and which program does the converting. Check the output instead of trusting the route.

What about multi-page TIFFs?

Each page in a multi-page TIFF has its own set of tags, so metadata can sit on any page, not just the first. Fax software and document scanners make a lot of these. In our test, a 3-page ImageMagick TIFF kept the XMP and color profile, and -strip removed them and kept all three pages. Some converters only keep the first page when they convert, so count the pages afterwards.

How do I check a TIFF for hidden metadata?

Our EXIF viewer reads TIFF files in your browser. On our Pillow TIFF it showed the camera, the author name and the GPS coordinates, along with a location warning. It lists the TIFF structure tags too (strip offsets, bits per sample), which you can ignore.

It doesn't show XMP. On the ImageMagick TIFF it found no EXIF or GPS, which was correct, but it didn't surface the author name sitting in the XMP block. For that, open the TIFF in a text editor and search for xmpmeta or your name. XMP is stored as plain text, so a hit means it's there. ExifTool reads every block, including XMP and IPTC, if you want the full list.

How do I remove metadata from a TIFF?

  • Keep it as TIFF: convert in.tif -strip out.tif with ImageMagick removed everything in our tests, including the color profile, and kept all pages. ExifTool's -all= does the same without re-encoding the image.
  • Don't need TIFF: most people sharing a TIFF online don't. Convert it to JPEG or PNG with -strip, then confirm with the EXIF viewer. Our image metadata remover takes JPEG and PNG.
  • Want it smaller too: TIFFs are huge. Our test photo went from 294 KB as a JPEG to 5.8 MB as an uncompressed TIFF. Chrome and Firefox can't open TIFFs (Safari can), so browser tools, including our image compressor, can't read one directly. Convert to PNG or JPEG first, then compress.

Frequently Asked Questions

Do TIFF files contain EXIF data?

They can. EXIF is built on TIFF's own tag structure, so a TIFF can hold camera details, dates, GPS coordinates, XMP, IPTC and a color profile. Whether a particular TIFF has them depends on the camera, scanner or converter that made it.

Does converting a JPG to TIFF remove GPS data?

It depends on the software. In our tests ImageMagick 6.9 dropped EXIF and GPS but kept XMP, and Pillow dropped everything except the color profile unless the EXIF was passed in, in which case it kept the GPS.

How do I remove metadata from a TIFF file?

Run convert in.tif -strip out.tif with ImageMagick, or exiftool -all= in.tif. Both remove EXIF, GPS, XMP and the color profile. ImageMagick kept every page of a multi-page TIFF in our test.

Can I view TIFF metadata in a browser?

Yes. A browser-based EXIF viewer can read TIFF tags, including GPS, even though Chrome and Firefox can't display TIFF images. XMP may not show up, so search the file for xmpmeta in a text editor as well.

Do scanned TIFFs have metadata?

Usually some. Scanners and scanning apps typically write the device make and model, software, resolution and date, and some add an artist name from the computer's user account. Scans rarely include GPS.
