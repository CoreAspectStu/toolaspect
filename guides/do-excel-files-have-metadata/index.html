Do Excel Files Have Metadata?

📄 6 min readUpdated November 4, 2026

Yes. Every .xlsx carries properties such as the author and dates, and it can also hold things that aren't labeled metadata at all, such as comment authors and hidden sheets. We built a test workbook and cleaned it several ways. Clearing the properties, including with our own tool, left the hidden data in place.

What metadata does an Excel file store?

An .xlsx file is really a ZIP folder of XML files, so you can rename a copy to .zip and read it yourself. Some of what's inside describes the file, and some of it is content most people forget is there:

What it revealsWhere it livesWhere you can see it in Excel
Author, last saved by, title, subject, keywords, created and modified datesdocProps/core.xmlFile > Info
Company, manager, app version, editing time, sheet namesdocProps/app.xmlFile > Info > Show All Properties (partly)
Custom properties, such as sensitivity labelsdocProps/custom.xmlAdvanced Properties
Comment and note authorsxl/comments files, plus a people list for threaded commentsHover or the Comments pane
Hidden sheets and their contentsxl/worksheets, flagged in xl/workbook.xmlRight-click a tab > Unhide
Defined namesxl/workbook.xmlFormulas > Name Manager
Paths to other workbooksxl/externalLinksData > Edit Links

Files saved by Excel can hold more: the workbook often records the folder it was last saved in, which may include a Windows username, and printer settings can be stored too. Our test file came from a Python library rather than Excel, so we didn't measure those, and it's worth checking your own copy.

How do you remove metadata in Excel?

Excel's Document Inspector goes further than a property cleaner. Save a copy first, because Microsoft warns that you may not be able to undo it. Then go to File > Info > Check for Issues > Inspect Document, and select Inspect. According to Microsoft's documentation, it handles these items differently:

ItemCan the inspector remove it?
Comments and annotationsYes
Document properties and personal infoYes
Headers and footersYes
Hidden rows, columns and worksheetsYes, but formulas that use them can change
Custom XML and invisible contentYes
External linksFinds only, fix by hand
Embedded files, macros and PivotTable cached dataFinds only, fix by hand
Hidden names, scenarios and active filtersFinds only, fix by hand

Unhide hidden sheets and look at them before removing anything. If a visible total depends on a hidden sheet, deleting that sheet can break the formula. To keep the numbers, copy the range and paste values first. On a shared workbook, some inspectors won't run until you turn sharing off on a copy.

No Excel on this computer? Our Document Metadata Remover clears properties in your browser with no upload, and you can open the file in the XLSX viewer to look at its contents. Remove the hidden sheets and comments before that step, though, since no property cleaner will do it.

Does saving as CSV or PDF remove the metadata?

CSV does, mostly as a side effect. It has nowhere to put properties, comments or formulas, so the export is only values. Our XLSX to CSV converter wrote the first sheet with no trace of the name. Be careful with two things. CSV loses your formulas and formatting, so it isn't a substitute when someone needs a working model. And hidden sheets aren't truly hidden from a converter: ours showed "Salaries" as a normal tab you could export, so a hidden sheet can leak if you export everything.

PDF is a different file with its own metadata. Our one-sheet test through Excel to PDF wrote only the generator's name, with no author, but Excel's own export can copy document properties across. A two-sheet workbook converted too when we retested on November 4, with both sheets in the PDF. We cover what to check in Do PDF Files Have Metadata? Hidden data won't print from Excel unless you unhide it, though our converter's notes say hidden rows and columns are included, so look over the output.

What should you check before you send a spreadsheet?

  1. Right-click any tab and see if Unhide is available.
  2. Open Name Manager and look for names you don't recognize. They can quietly point to deleted data.
  3. Check Data > Edit Links. A link can expose a path like a server or a client folder.
  4. Check for PivotTables. Their cached data can include rows you've filtered out of view.
  5. Run Document Inspector on a copy, or clear properties with a tool.
  6. Open the copy and confirm the totals still match.

If you only need someone to see the numbers, send values in a new workbook, or a CSV. The file can't reveal what was never copied into it. The same habits apply to other Office files, as we explain in removing metadata from Word documents. If you're dealing with a legal hold or a records request, ask your attorney before you clean anything.

Frequently Asked Questions

Can you tell who created an Excel file?

Often, yes. Excel records an author and a last-saved-by name under File > Info, usually from the Office account or user name of whoever made the file. It's easy to change or copy from a template, so treat it as a clue and not as proof.

Does Excel keep a history of who edited a file?

A regular .xlsx stores only the last person to save, not a full history. Workbooks in OneDrive or SharePoint do keep version history on the server, but that record isn't inside a copy you download and email.

Does Document Inspector remove everything?

No. It can remove properties, comments, hidden sheets and more, but Microsoft says it only reports external links, embedded objects, macros and PivotTable cached data, so you have to deal with those by hand. Always run it on a copy.

Does copying sheets to a new workbook remove metadata?

It removes the old file's properties, but your own name goes on the new file, and formulas that point to the old workbook can create external links. Paste values only if you want a clean break, then check Data > Edit Links.

Do CSV files have metadata?

Not inside the file. A CSV is plain text with no property fields, comments or hidden sheets. Your computer still tracks basic details such as the file's dates, and those can change when it's copied or emailed.
