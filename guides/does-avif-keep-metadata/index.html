Does AVIF Keep Metadata? What We Found in 8 Tests

📄 6 min readUpdated October 26, 2026

Yes, AVIF files can carry EXIF and XMP metadata, including GPS coordinates. Whether conversion removes it depends entirely on the tool. We built a test AVIF with a location, an author name and a color profile, then ran it through ImageMagick, Python's Pillow and Chrome. ImageMagick copied the GPS location into JPG, PNG and WebP, while the browser removed it every time.

Can AVIF files contain metadata?

Yes. AVIF uses the same container format as HEIC, which stores everything as numbered items and boxes. The photo is one item, and EXIF and XMP metadata are separate items stored alongside it. That's all they need to carry the same location data a phone JPEG does.

Part of the fileWhat it holdsWhere you'll see it

Exif itemCamera, date, author, software, GPSConverted photos, some phones and editors
mime item (XMP)Creator, copyright, keywords, edit historyAdobe apps, asset tools
colr boxColor profile, or a short color-space codeAlmost every AVIF

To test this, we made a 1600 × 1200 AVIF with Python's Pillow library containing a camera make and model, an author name, a capture date, GPS coordinates, an XMP creator field and an sRGB color profile. The file came to 189 KB, of which the EXIF block was under 300 bytes. Then we ran it through the tools people actually use.

The results don't follow any obvious logic, which is the useful lesson here. ImageMagick 6 carried the GPS location into every other format, and in the PNG it wrote the coordinates twice: once as a binary EXIF block and again as plain-text notes anyone can read in a text editor. Yet re-saving the same AVIF as AVIF threw away everything, including the color profile. Our ImageMagick build read only the EXIF part of the file, so the XMP and color profile never made it out on any route. Newer ImageMagick 7 builds may behave differently, so check rather than assume.

Pillow, the library behind a lot of Python scripts and web apps, dropped EXIF and XMP on a default save in every format we tried. It only keeps them when the code passes them through on purpose.

Does converting a photo to AVIF strip its metadata?

Not reliably. A converter can copy the EXIF block straight in, and Pillow does exactly that when it's asked to. Whether a given app or website does depends on how it was written. If you're converting photos to AVIF to post or send, check the output, don't assume.

Browser-based converters are a special case. Chrome can display AVIF but can't create it from a web page's canvas: when we asked for an AVIF, it silently handed back a PNG. So a site that claims to make AVIF in your browser is either using its own encoder or uploading your file to a server.

How do I check an AVIF for location data?

Open it in the EXIF viewer. It reads AVIF files in the browser and shows the camera, date and GPS fields when they're there; in our test it found the exact coordinates we embedded. It doesn't show XMP, which is where editing apps keep creator and copyright details, so a clean result means no EXIF location, not necessarily no metadata at all.

On a computer, Windows File Explorer's Properties, Details tab and the Mac Finder's Get Info panel may or may not read AVIF depending on your system version, so a browser tool is the more consistent check.

How do I remove metadata from an AVIF?

The easiest way is to re-encode it in the browser. Drop the AVIF into the image compressor and save it as WebP or JPG: in our test, both outputs had no EXIF, no GPS and no XMP, only a standard sRGB color profile. The file never leaves your device. The catch is that you end up with WebP or JPG rather than AVIF, because browsers can't encode AVIF.

If you need to stay in AVIF, use a desktop tool that can write AVIF and strip metadata, then check the result. ImageMagick's AVIF-to-AVIF route stripped everything in our test, but that's a side effect of how our build handles AVIF, not a documented feature. Our metadata remover only accepts JPG and PNG, so convert first if you want to use it.

Frequently Asked Questions

Does AVIF store EXIF data?

Yes. AVIF can hold EXIF and XMP metadata as separate items next to the image, including GPS coordinates. Whether a particular AVIF has any depends on the camera, app or converter that made it.

Does converting AVIF to JPG remove metadata?

It depends on the tool. ImageMagick 6 kept the camera details and GPS location when converting our test AVIF to JPG, PNG and WebP. Pillow's default save and browser canvas conversion removed them.

Can I see the GPS location in an AVIF?

Yes, if it's there. A browser-based EXIF viewer that supports AVIF will show the latitude and longitude. In our test the EXIF viewer read the exact coordinates we embedded.

How do I strip metadata from an AVIF without uploading it?

Re-encode it in the browser. Converting an AVIF to WebP or JPG with a canvas-based image compressor removed all EXIF, GPS and XMP in our test, leaving only a standard color profile. The output won't be AVIF, though.

Can browsers save images as AVIF?

Not through the standard canvas method. Chrome 145 can display AVIF, but when asked to export a canvas as AVIF it returned a PNG instead. Sites that output AVIF use their own encoder or a server.
