What does flattening actually mean?

A filled PDF is two layers: the page, and a set of interactive objects sitting on top of it — text boxes, checkboxes, signature fields, each holding a value plus the machinery to edit it. Flattening draws those values directly into the page content and deletes the interactive layer. Visually the document hardly changes. Structurally, everything the reader could click, tab into, reset, or accidentally clear is gone.

The canonical demonstration: a one-page form with a name box and a checkbox has 2 interactive fields. Flatten it, reload, and the form reports 0 fields — the typed name prints exactly where it was, now as ordinary page content.

Why is everyone asking for flat files?

  • Print shops — prepress and variable-data pipelines re-process files; interactive fields and annotations are where values shift or vanish.
  • HR, courts, insurers — a flat copy can't be edited after submission, which is the point of submitting it.
  • Upload portals — some form processors reject interactive files outright or double-count fields.
  • Archives — a flattened version is frozen: it renders the same everywhere, forever.

Forms mode is surgical and reversible-adjacent — nothing about the page changes except the field layer. Press mode is the nuclear option: render every page to an image (150–300 DPI) and rebuild the PDF from those images. Nothing interactive survives a raster, which is precisely its job; the tradeoffs are a bigger file and text you can no longer search or copy.

On DPI: PDF pages are measured in points, 72 to the inch, so rasterizing multiplies by DPI÷72. A US Letter page (612×792 points) becomes 1275×1650 pixels at 150 DPI, 1700×2200 at 200 DPI, 2550×3300 at 300 DPI. 200 is the standard print-shop ask; go 300 only when they say press quality.

Isn't print-to-PDF the same thing?

Close, but worse. Printing to PDF does produce a flat file, but it re-renders the whole document: internal links die, text can come back as outlines or shift a fraction of a point, and quality ratchets down with every round-trip. Flattening edits the original file — the page content stream is untouched, text stays selectable, and the output is one generation closer to the source. Save print-to-PDF for when flattening isn't available and quality doesn't matter.

The one-way warning

Flattening cannot be undone — the field structure is deleted, not hidden. So the workflow that never bites you: keep the original with live fields in your records, flatten a copy for whoever asked, and name it something you'll recognize (contract-flattened.pdf, not contract(3).pdf). If you flatten the only copy of a form you might need to edit, retyping it is on you.
