Why Does PDF Text Copy as Gibberish? (And How to Fix It)

📄 6 min readUpdated October 20, 2026

You copy a paragraph from a PDF and paste symbols, shifted letters or empty boxes, even though the page reads perfectly. The page is fine. The map that tells software which letter each glyph stands for is missing or broken. Here's how to recognize each kind of mess and get clean text out.

Why does copied PDF text turn into gibberish?

Because a PDF doesn't store words. It stores instructions to draw glyphs, the shapes in a font, at positions on a page. When you copy, the viewer has to work backwards from "glyph number 37 in this font" to "the letter T". If the file tells it how, the copy is perfect. If it doesn't, the viewer guesses, and a wrong guess gives you symbols, shifted letters or empty boxes while the page itself looks fine.

The piece that does the translating is called a ToUnicode map. Programs that create PDFs are supposed to include one for every font, and most modern ones do. Problems usually come from older software, some print-to-PDF drivers, files with fonts subset under a custom encoding, and now and then a publisher that scrambles the map deliberately to discourage copying.

The first row is the classic. The font's internal numbering doesn't match standard letter codes, so every character comes out as a different but consistent one. That consistency is a tell: if every "e" turns into the same symbol, it's an encoding problem, not a damaged file, and repairing the PDF won't change it.

The lesson is that a missing ToUnicode map isn't fatal on its own. Good extractors fall back on the font's built-in encoding and glyph names, and for standard fonts those are usually enough. Gibberish appears when the fallback has nothing meaningful to work with, which in our sample happened to decorative characters rather than words. A different extractor can do better or worse on the same file, though, so if one tool gives you garbage, try another before reaching for OCR.

How do I fix gibberish text from a PDF?

  1. Try a different extractor. Paste the same page from another viewer, or run the file through PDF to Text. It runs in your browser, so the file isn't uploaded anywhere.
  2. Fix ligatures with find and replace. If only "fi", "fl", "ff" and "ffi" are broken, search for the odd character and replace it with the letters. It's quick and keeps everything else.
  3. OCR the page. If the encoding is genuinely broken, stop trying to decode it and read the page as an image instead. OCR PDF renders each page and recognizes the letters it sees, ignoring the broken map entirely. Expect a few errors on small print and tables, so proofread numbers.
  4. Ask for the source. If it's a document you need regularly, the Word file or a re-export from the original app, with "embed fonts" on, solves it for good.

Can a PDF be made to copy as gibberish on purpose?

Yes. Some publishers subset fonts with scrambled codes so that the page reads fine but copied text doesn't. It's a crude form of copy protection and it also breaks screen readers, search and accessibility checks. A file can also set a permission flag that tells viewers not to allow copying; that's different, because the text is intact and the viewer simply refuses. Either way, the text you see on screen is still there to read, and OCR or a careful retype gets it out. If you need a picture of the page rather than its text, PDF to JPG does that directly.

If the problem is a blank page rather than garbled text, that's a different set of causes; see why is my PDF blank. For pulling clean text from normal files, how to extract text from a PDF covers columns, page ranges and tables.

Frequently Asked Questions

Why does text from a PDF paste as random symbols?

The font in the PDF has no ToUnicode map, or a broken one, so the viewer can't tell which letter each glyph stands for. It guesses, and the guess comes out as symbols or shifted letters even though the page looks fine. OCR fixes it by reading the page as an image.

Can a corrupted PDF cause gibberish when copying?

Rarely. Real corruption usually stops pages from opening or leaves them blank. If every instance of a letter turns into the same wrong character, the file isn't damaged, the font encoding is, and repairing the PDF won't help.

How do I copy text from a PDF without losing formatting?

Plain copy and paste only carries text, not layout. For a handful of lines, copy one column at a time. For tables, extract page by page and rebuild the table, or ask for the original source file.

Is OCR better than copying text from a PDF?

Only when the text layer is missing or broken. When the PDF has a good text layer, copying is exact and OCR can only add errors. Use OCR when the paste is gibberish, empty, or the PDF is a scan.

Why do fi and fl disappear when I copy from a PDF?

Many fonts draw fi, fl, ff and ffi as single combined glyphs called ligatures. If the PDF doesn't map those glyphs back to the separate letters, they paste as one unusual character or nothing at all. Find and replace fixes it.
