# Outreach: ToolAspect Embed Widgets

Assets:
- Live embeds: https://toolaspect.com/embed/
- Targets: `targets.md` (50 sites, angles keyed B/A/S/D)
- Emails: `templates/email-templates.md`

## Cadence

- **10 new sends per week** (Mon–Wed sends, 2–4/day max from one inbox).
- **Follow-up after 5 days**, one time only. Reply in-thread, two sentences, restate the CTA link.
- No reply after follow-up = mark `dead`, move on. Re-touch at 90 days only if the site publishes new relevant content.
- Personalize the bracketed fields every send; reference one specific page or post. Skip sends where you can't find something real to reference.
- Rotate angles: aim for roughly 4 blogger, 3 agency, 3 supplier sends per week.

## Tracking (outreach.csv)

Columns:

`id,site,url,angle,best_fit_calculator,contact_page,contact_name,send_date,followup_date,replied,status,notes`

- `angle`: B / A / S / D (from targets.md)
- `status`: queued / sent / followup_sent / replied / dead / deal
- `replied`: y / n
- `notes`: anything personal for the next touch (their post title, who they are)

Keep it in this folder. Update the same day you send — the list is only useful if it's current.

## Rules

- Never invent an email address. If no contact path exists in 3 minutes of looking, mark the target dead and swap in a regional equivalent.
- One clear CTA per email (the embed link). No attachments on first contact.
