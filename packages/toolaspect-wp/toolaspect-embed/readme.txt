Embed 600+ free calculators and converters from ToolAspect with one shortcode.

== Description ==

Embed any ToolAspect calculator, converter or utility widget on your WordPress site:

`[toolaspect tool="401k-match-calculator"]`

* 600+ tools: finance, health, SEO, math, unit converters, PDF/image utilities
* Zero setup — no API keys, no accounts
* Runs client-side, privacy-friendly
* Mobile-responsive iframes with lazy loading

Find your tool slug at https://toolaspect.com/embeds

== Installation ==

1. Upload the `toolaspect-embed` folder to `/wp-content/plugins/`
2. Activate the plugin
3. Add `[toolaspect tool="slug"]` to any post or page
