How the Window Rough Opening Calculator Works

Enter the window's nominal unit size (the size printed on the label, e.g. a "3050" is 3 ft 0 in wide × 5 ft 0 in tall) and the shim space, and the calculator returns the rough opening to frame stud-to-stud: RO = unit size + shim space on each side. The standard shim allowance is 1/2 in per side for new-construction windows with nailing fins — 1 in total added to width and height — leaving room to plumb, level, and square the unit with shims before insulation and casing.

Formulas Used

  • Rough opening width: RO_w = unit width + 2 × shim space
  • Rough opening height: RO_h = unit height + 2 × shim space
  • Typical shim space: 1/2 in per side for finned new-construction units
  • Window size notation: a "3050" = 30 in wide × 50 in high (first two digits = feet, second two = inches ×10)

Worked Example

A 36 × 48 in window with the standard 1/2 in shim space per side: RO width = 36 + 1 = 37 in, RO height = 48 + 1 = 49 in. Frame the opening 37 × 49 in, set the window against the interior stop, shim the sides at top, middle, and bottom, and check both diagonals for square before nailing the fin. Always confirm the manufacturer's stated RO on the spec sheet — some brands call for 1/4 in and others 3/4 in per side.

Frequently Asked Questions

What is a rough opening? The framed hole in the wall — stud to stud, sill to header — that the window unit drops into. It must be slightly larger than the unit so shims can plumb and level it.

How much bigger than the window should the RO be? Typically 1/2 in per side and per head/sill (1 in total each direction). Tight openings bow the frame; oversized openings over 3/4 in per side make shimming difficult and can affect fastening.

What about door rough openings? Doors usually get a bit more: 2 in wider than the slab (1 in per side for jambs and shims) and about 2-1/2 in taller for the threshold/jamb and clearance.

Replacement vs new construction? Pocket replacement windows fit inside the existing frame, so the RO is the existing opening itself, measured at three points each direction and use the smallest. New-construction units with fins get the full framed RO calculated here.
