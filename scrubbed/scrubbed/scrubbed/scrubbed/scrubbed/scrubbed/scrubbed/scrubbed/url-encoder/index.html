What is URL Encoding?

URL encoding converts special characters into a format that can be transmitted over the internet. Characters like spaces, ampersands, and non-ASCII characters are replaced with percent-encoded sequences (e.g., space becomes %20).

When to Use URL Encoding

  • Building query strings with special characters
  • Passing data in URL parameters
  • Encoding API request URLs
  • Handling international characters in URLs

encodeURI vs encodeURIComponent

Use encodeURI for full URLs (keeps :/?#&=@). Use encodeURIComponent for individual query parameter values (encodes everything except A-Za-z0-9-_.!~*'()).
