Text Case Formats Explained

  • UPPERCASE: ALL CAPS — for emphasis, headings, acronyms
  • lowercase: all small — casual style, URLs
  • Title Case: Capitalize Each Word — book titles, headlines
  • Sentence case: Only first word capitalized — normal prose
  • camelCase: firstWordLower, restCapitalized — JavaScript variables
  • PascalCase: EveryWordCapitalized — class names, React components
  • snake_case: words_with_underscores — Python, Ruby, database fields
  • kebab-case: words-with-hyphens — URLs, CSS classes, file names
  • CONSTANT_CASE: ALL_CAPS_UNDERSCORES — constants, env variables
  • aLtErNaTiNg: silly meme case
  • InVeRsE: swaps existing case
