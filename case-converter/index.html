Available Case Conversion Modes

UPPERCASE: Converts all characters to capital letters. Example: "hello world" becomes "HELLO WORLD". Useful for headlines, warnings, acronyms, and emphasis in design.

lowercase: Converts all characters to small letters. Example: "Hello WORLD" becomes "hello world". Essential for URLs, email addresses, code keywords, and reducing the visual intensity of text.

Title Case: Capitalizes the first letter of every word. Example: "the art of programming" becomes "The Art Of Programming". Used for book titles, article headlines, movie titles, and proper nouns.

Sentence case: Capitalizes only the first letter of each sentence. Example: "hello. how are you?" becomes "Hello. How are you?". The natural case for paragraphs and body text in formal writing.

camelCase: First word lowercase, subsequent words capitalized, no spaces. Example: "user account id" becomes "userAccountId". The standard naming convention for JavaScript variables, function names, and method names.

PascalCase: Every word capitalized, no spaces. Example: "user account" becomes "UserAccount". Used for class names in JavaScript, TypeScript, C#, Java, and interface definitions.

snake_case: All words lowercase, separated by underscores. Example: "user account id" becomes "user_account_id". Common in Python, Ruby, Rust variable names, and database column names.

kebab-case: All words lowercase, separated by hyphens. Example: "background color" becomes "background-color". Used in CSS properties, URLs, file names, and HTML attribute values.

CONSTANT_CASE: All uppercase with underscores. Example: "max retries" becomes "MAX_RETRIES". Used for constants and enums in virtually every programming language.

aLtErNaTiNg: Alternates between lowercase and uppercase. Example: "hello" becomes "hElLo". Popular for meme text and stylistic purposes in social media.

InVeRsE (Swap Case): Swaps the case of each character. Example: "Hello World" becomes "hELLO wORLD". Useful for reversing accidental caps lock or creating stylistic text.

Programming Naming Conventions Explained

Different programming languages and frameworks have established conventions for naming variables, functions, classes, and constants. Understanding these conventions helps you write code that follows community standards and is more readable to other developers.

camelCase is the dominant convention in JavaScript, TypeScript, Java, and Swift for variables and function names. The first word starts lowercase, and each subsequent word starts uppercase: firstName, getUserData(), isAuthenticated. This convention developed because it's compact and makes word boundaries clear without extra characters.

PascalCase (also called UpperCamelCase) is used for class names, constructor functions, interfaces, and types across JavaScript, TypeScript, C#, Java, and many other languages: UserController, HttpClient, ValidationError. The capital first letter helps distinguish types from instances at a glance.

snake_case is the standard in Python, Ruby, Rust, and PHP for variable and function names: user_name, get_user_data(), is_authenticated. It's also common for database column names (e.g., created_at, user_id) and is used in REST API JSON field naming by some frameworks.

kebab-case is the standard for CSS class names and custom properties: nav-bar, text-primary, --brand-color. It's also widely used in URLs, file names, and configuration keys. HTML custom element names require kebab-case with at least one hyphen: my-custom-element.

CONSTANT_CASE is universally used for constants and configuration values that should never change: MAX_CONNECTIONS, DEFAULT_TIMEOUT, API_VERSION. The uppercase signals immutability and makes constants visually distinct from variables.

When to Use Each Case Style

Choosing the right case style depends on your context. For written content and documents, use sentence case for body paragraphs and title case for headings and titles. For social media, UPPERCASE creates emphasis (but use sparingly to avoid appearing aggressive), while lowercase conveys a casual, conversational tone popular on platforms like X and TikTok.

For web development, kebab-case is the standard for CSS class names and IDs. In JavaScript, use camelCase for variables and functions, PascalCase for classes and React components. In Python and Ruby, snake_case is the norm. When working with databases, snake_case is preferred for column names because it's database-agnostic and avoids case sensitivity issues that can arise with mixed case in SQL.

For SEO and web URLs, use kebab-case with lowercase letters. Search engines like Google treat hyphens as word separators, making "how-to-bake-bread" more SEO-friendly than "how_to_bake_bread" or "HowToBakeBread". Underscores are treated as part of the same word by some search engines.

Frequently Asked Questions

What is the difference between Title Case and Sentence case?

Title Case capitalizes the first letter of every word: "The Quick Brown Fox." Sentence case only capitalizes the first letter of each sentence: "The quick brown fox." Title Case is used for titles and headlines, while sentence case is used for body text and paragraphs.

What is camelCase used for?

camelCase is the standard naming convention for variables, functions, and methods in JavaScript, TypeScript, Java, and Swift. The first word is lowercase, subsequent words start uppercase: firstName, getUserData(). It makes identifiers compact and readable without spaces or underscores.

What is the difference between camelCase and PascalCase?

In camelCase, the first word starts lowercase: userName. In PascalCase (also called UpperCamelCase), every word including the first starts uppercase: UserName. camelCase is used for variables and functions; PascalCase is used for classes, interfaces, and types.

What is kebab-case and when should I use it?

kebab-case uses hyphens to separate words: background-color. It's the standard for CSS property names, CSS class names, URL paths, and HTML custom element names. Search engines treat hyphens as word separators, making kebab-case ideal for SEO-friendly URLs.
