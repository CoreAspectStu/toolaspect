Full pre-call check

Going into an interview, stand-up or client call? Run the trio in order — it takes about a minute:

  1. 1Test your camera — confirm the picture is live and the privacy shutter is open.
  2. 2Test your microphone — record a few words and play them back.
  3. 3Test your speakers — verify you can hear both left and right channels.

If all three pass, your meeting app will work. If one fails, each test page includes troubleshooting steps for the most common causes (permissions, exclusive device locks, privacy shutters).

About these device tests

Every test on this page runs entirely in your browser using standard web APIs — getUserMedia for camera and microphone, the Web Audio API for playback, the Fullscreen API for screen tests. There is no account, no upload and no server-side processing: audio and video never leave your device, and closing a tab releases the hardware immediately.

Frequently asked questions

Is it really private? Yes. The camera and mic tests only render your stream locally so you can see and hear it yourself. Nothing is recorded to disk or sent over the network — you can watch the browser's camera/mic indicator disappear the moment you press Stop.

Why does my browser ask for permission? Browsers require an explicit grant before any page can access a camera or microphone. You only need to allow it once per site; if you deny it by accident, click the lock icon in the address bar and change the Camera or Microphone setting to Allow.

Do these work on phones? Camera, mic, speaker, screen and browser tests all work on mobile browsers. The keyboard test needs a physical keyboard, so it's best on a laptop or desktop.
